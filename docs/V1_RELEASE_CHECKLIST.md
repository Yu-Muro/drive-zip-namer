- [ ] macOS / Chrome Stable で通常の複数ファイルダウンロードを命名できる

- [ ] リスト表示とグリッド表示で `{count}` が一致する
- [ ] マイドライブ、共有アイテム、共有ドライブで `{folder}` を確認する
- [ ] 2つのDriveタブから連続して実行しても名前が混ざらない
- [ ] 分割ZIPが `_part2`, `_part3` となる
- [ ] 名前入力の取消・タイムアウト・タブ終了後もダウンロードが完了する
- [ ] v0.3をインストールした状態から更新し、設定・プリセット・履歴が保持される
